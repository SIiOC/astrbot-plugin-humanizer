astrbot_plugin_wanna_be_human v4.2.0 — 好想成为人类啊插件
=====================================================

【安装】
- WebUI 安装（推荐）：插件管理 → 安装插件 → 上传 zip
- 手动放置：本文件夹复制到 AstrBot 的 data/plugins/ 下并重启
- 要求 AstrBot ≥ 4.5.7；控制台页面需 ≥ 4.24.2（旧版本自动跳过）

【功能】
- 去 AI 痕迹：每条回复自动清理套话、填充语等写作痕迹
- 规则清理：本地去除套话/填充语等 AI 写作痕迹（v4.1.0 起不再提供 LLM 深度改写）
- 说话风格：从对话语料提炼你的说话方式注入回复
- 消息防抖（v3.2 并入，默认开）：合并短时间内连续发送的私聊消息再回复，
  支持自适应等待、撤回过滤、输入状态感知
- 时间流动感知（v3.0，默认开）：每次对话注入当前时间与距上次交流的时长
  （30 分钟内视为连续对话不注入；三档粒度可选）
- 动态一天状态：随真实时间注入"此刻在做什么/心情"；
  可选开启 LLM 每日生活时间线（每天 00:05 自动生成当天安排，跨天连贯，
  默认关，每天消耗一次模型调用）
- 主动聊天（可选）：沉默后主动发消息，支持勿扰时段与完整管线注入；
  对方发言或正在输入时自动让位（v3.2 插话丢弃）；
  支持会话白名单（仅对指定会话生效）
- 发送纪律（v3.3.1，默认开）：正文与发消息工具二选一，防同一回复双通道重复
- 打字延迟（v3.4，默认开）：回复前按拟人节奏延迟后再发送
- 情绪/记忆（v3.5~v3.9）：情绪惯性、历法感知、冷落弧线、
  主动消息 v2（话题选择/轻追问/沉默自适应）、语言风格趋同（见 README）
- v4.0 大版本：架构重构（装配层/services/core 分层）；真人感规则库扩容
  至 31 条并引入 S1/S2/S3 严重度分级与子集轮换注入；勿扰时段支持星期
  前缀 + 活跃时段白名单；情绪×对话热度耦合（热聊升温/冷场降温）；
  控制台实时事件流与总览仪表盘

【控制台】（插件管理 → 打开插件 UI 界面，共 8 页）
总览 · 配置 · 语料与风格 · 主动聊天 · 记录回看 · 真人感规则 · 成长 · 统计
配置页下拉选择：嵌入提供商 / 提炼模型 / 时间线生成模型 /
检索重排提供商 / 风格 / 间隙粒度。
（注：`自定义语料文件` 与 `指令前缀列表` 两项在 AstrBot 原生配置表单里编辑，
控制台不渲染这两个控件；语料上传请用「语料与风格」页。）

【配置】
六个语义分区（v4.1.1 起）：
表达·说话风格与语料 / 表达·润色去痕 / 感知·时间与节奏 / 感知·情绪惯性 /
主动·聊天与追问 / 发送·延迟与防护。详见 README.md。

【v4.2.0 起】不再自动拆分回复：普通回复与主动消息都整条发送，
  不做机械断句；句尾语气词/省略号只由提示词与模型生成，后处理不再补词。

  墙钟行自动跟随宿主 datetime_system_prompt。

【升级】
- 升级后建议重启 AstrBot（热重载对已加载的子模块不生效）。
- 从 v3.3.0/v3.4.x 升级：配置自动补齐，无手动步骤；v3.4.2 起已移除
  「正在输入」指示（实测 QQ 9.9.32 + NapCat 输入状态双向不传播）。
- 从 v3.1.x 及更早升级：若此前使用过其它消息防抖方案，请先停用并移除，
  避免两层防抖叠加延迟、行为错乱（防抖能力已内置本插件）。
- 从 v2.x 升级：若此前使用过其它时间流动感知方案，请先停用并移除，
  避免重复注入（时间感知能力已内置本插件）。
- 从旧名 astrbot_plugin_humanizer 升级（v3.3.0 更名）：AstrBot 停止后做三步——
  ① 将 data/plugins/astrbot_plugin_humanizer 整个目录删除，放入本插件目录
  （data/plugins/astrbot_plugin_wanna_be_human）；② 将
  data/config/astrbot_plugin_humanizer_config.json 改名为
  astrbot_plugin_wanna_be_human_config.json（配置与白名单原样保留）；
  ③ 将 data/plugin_data/astrbot_plugin_humanizer 目录改名为
  astrbot_plugin_wanna_be_human（统计/主动状态/生活线/风格档案全保留）。
  知识库（human_style_ 前缀）无需重建。
