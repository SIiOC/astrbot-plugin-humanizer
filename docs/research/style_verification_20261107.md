## 复现

在 AstrBot 根目录激活 venv 后：

```powershell
$env:PYTHONPATH='<AstrBot 根目录>'
$env:ASTRBOT_ROOT=$env:PYTHONPATH
python tools\style_audit.py --from-log --limit 20
```

只看日志加载后的新回复可用 `--from-log` 配合自行截取日志；`--limit` 取最后 N 条实际发送。
